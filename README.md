# CS141 Coursework 2: λGPT

This repository contains my submission for the second coursework of [CS141 Functional Programming](https://courses.warwick.ac.uk/modules/2025/CS141-15) 2025-2026. It consists of a chatbot created in Haskell through implementing a REPL from scratch. Through a combination of monad, API, and parser-combinator usage, my chatbot can give information about dates, do integer calculations, and return live public transport information. This chatbot also has a memory, i.e. it can store and return user-provided information.

To utilise the public transport features of this chatbot, you will need to provide a key for the Transport for Greater Manchester API in a `.env` file.

I received a high first as defined by the University of Warwick's [undergraduate mark scale](https://warwick.ac.uk/services/aro/dar/quality/categories/examinations/marking/ug/).
